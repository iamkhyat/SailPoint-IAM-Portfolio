# ⚖️ Role vs Access Profile

## 🎯 Objective
Compare IdentityIQ roles with IdentityNow access profiles.

---

## 🧠 IAM Design Approach

IdentityIQ:
- Complex RBAC

IdentityNow:
- Simplified access model

---

## 🔑 Comparison

| Feature | IdentityIQ | IdentityNow |
|--------|-----------|------------|
| Model | Roles | Access Profiles |
| Complexity | High | Low |
| Use Case | Enterprise RBAC | SaaS IAM |

---

## 🎤 Interview Talking Points

“IdentityNow simplifies RBAC by using access profiles instead of complex role hierarchies.”

---

## 🚀 Key Takeaways

- Cloud IAM favors simplicity
