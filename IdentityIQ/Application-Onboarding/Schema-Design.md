# 🧩 Schema Design

## 🎯 Objective
Define how account and entitlement data is structured in IdentityIQ.

---

## 🏢 Business Scenario
Applications store:
- User accounts
- Permissions/roles

These must be represented correctly in IAM.

---

## 🧠 IAM Design Approach
- Separate account vs entitlement schema
- Map attributes clearly
- Ensure identity correlation

---

## 🔑 Key SailPoint Concepts Used
- Account Schema
- Entitlement Schema
- Attributes
- Identity Mapping

---

## ⚙️ Step-by-Step Flow

1. Identify account attributes (username, email)  
2. Define entitlements (roles, groups)  
3. Map attributes  
4. Set identity attribute  
5. Validate via aggregation  

---

## ⚠️ Common Issues & Troubleshooting
- Missing attributes  
- Incorrect mapping  
- Multi-value issues  

---

## 🎤 Interview Talking Points
- Account vs entitlement schema  
- Importance of mapping  
- Identity attribute role
