# 🔄 Aggregation Process

## 🎯 Objective
Explain how IdentityIQ collects account and entitlement data.

---

## 🏢 Business Scenario
Applications continuously change:
- New users added
- Access updated

IAM must stay synchronized.

---

## 🧠 IAM Design Approach
- Use scheduled aggregation
- Support full and incremental loads

---

## 🔑 Key SailPoint Concepts Used
- Aggregation Task
- Full Aggregation
- Incremental Aggregation

---

## ⚙️ Step-by-Step Flow

1. Configure aggregation task  
2. Run full aggregation  
3. Store accounts in IdentityIQ  
4. Run incremental aggregation  
5. Trigger correlation  

---

## ⚠️ Common Issues & Troubleshooting
- No data fetched  
- Duplicate accounts  
- Performance issues  

---

## 🎤 Interview Talking Points
- Full vs incremental  
- Performance tuning  
- Scheduling
