# 🛠️ Application Onboarding Troubleshooting

## 🎯 Objective
Provide practical troubleshooting steps for onboarding issues.

---

## 🏢 Business Scenario
During onboarding:
- Integration issues occur
- Data inconsistencies happen

---

## 🧠 IAM Design Approach
- Identify issue layer:
  - Aggregation
  - Correlation
  - Provisioning

---

## 🔑 Key SailPoint Concepts Used
- Logs
- Task Results
- Identity Debug
- Provisioning

---

## ⚙️ Step-by-Step Flow

1. Identify issue type  
2. Check connector  
3. Validate schema  
4. Run aggregation  
5. Review logs  
6. Fix and retry  

---

## ⚠️ Common Issues & Troubleshooting

### Aggregation Failure
- Connector issue  
- Credential problem  

### Correlation Issue
- Attribute mismatch  

### Provisioning Failure
- Policy misconfiguration  

---

## 🎤 Interview Talking Points
- Debugging approach  
- Real-world failures  
- Importance of logs
