# 📘 Application Onboarding Overview

## 🎯 Objective
Explain the concept and importance of onboarding applications into IdentityIQ.

---

## 🏢 Business Scenario
Organizations manage access across multiple systems:
- Active Directory
- Databases
- SaaS applications

Manual access leads to:
- Security risks
- Audit failures

---

## 🧠 IAM Design Approach
- Treat each system as a managed application
- Standardize onboarding process
- Centralize governance in IdentityIQ

---

## 🔑 Key SailPoint Concepts Used
- Applications
- Connectors
- Schema
- Aggregation

---

## ⚙️ Step-by-Step Flow

1. Identify application type  
2. Select connector (LDAP/JDBC/REST)  
3. Configure connection  
4. Define schema  
5. Test connectivity  
6. Run aggregation  

---

## ⚠️ Common Issues & Troubleshooting
- Connection failure  
- Unsupported API  
- Incorrect schema mapping  

---

## 🎤 Interview Talking Points
- Types of connectors  
- Importance of onboarding  
- Differences between systems
